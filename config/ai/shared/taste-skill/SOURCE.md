# taste-skill

Vendored from https://github.com/leonxlnx/taste-skill at commit
`f624f37a8c650b9cc550253104925efe4c8de246` (MIT license).

`manifest.txt` records the upstream `SKILL.md` install names and source folders.
Run `bash script/common/setup_taste_skill.sh` from this dotfile repository to
link the skills into the installed agent runtimes. Existing unrelated skills
are preserved on name collisions.
